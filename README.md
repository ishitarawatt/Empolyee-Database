# 👥 Employee Database CLI App

> A menu-driven employee management system backed by SQLite.

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![SQLite](https://img.shields.io/badge/SQLite-003B57?style=flat-square&logo=sqlite&logoColor=white)

## Features

- ➕ Full **CRUD**: create, read, update, delete employees
- 🛡️ **Parameterised queries** to prevent SQL injection
- 💾 **Persistent** storage in `employees.db`
- 📋 Simple menu-driven command-line interface

## Run

```bash
git clone https://github.com/ishitarawatt/Empolyee-Database.git
cd Empolyee-Database
python employee_db.py
```

Python 3 only, since `sqlite3` is in the standard library.

## Files

| File | Purpose |
|---|---|
| `employee_db.py` | The application |
| `employees.db` | SQLite database |
